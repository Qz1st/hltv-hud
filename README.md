# HLTV HUD — счёт параллельного матча CS2 для OBS

Плашка в стиле PGL-оверлея: большие цифры — раунды текущей карты (синий CT, жёлтый T), кружочки под названием — карты (закрашенный = выиграна), в центре карта и номер раунда. Данные с HLTV, раунды вживую из скорбота.

## На сервере (по ссылке, ничего не качать)

Бесплатно на Render.com, без карты:

1. https://dashboard.render.com → **New → Web Service** → подключить репозиторий `Qz1st/hltv-hud`.
2. Поля: **Language** `Node`, **Build Command** `npm install --omit=dev`, **Start Command** `node server.js`, **Instance Type** `Free`. Остальное не трогать.
3. **Deploy Web Service**. Через 2–3 минуты будет адрес вида `https://hltv-hud-xxxx.onrender.com`.
4. Открыть адрес → **«+ Новый худ»** → пульт. В OBS: Источники → «+» → **Браузер** → адрес плашки `https://…/w/<id>`, размер **490×62**. В пульт — ссылку на матч с HLTV.

(Кнопка Blueprint с `render.yaml` тоже работает, но Render просит для неё карту.)

Каждый худ — своя плашка и свой пульт; сделайте сколько нужно для параллельных матчей. Ссылка на пульт — это пароль худа, не показывайте её на стриме. Пульт можно встроить в OBS: Док-панели → Пользовательские док-панели браузера.

**Про бесплатный Render:** без посетителей сервер засыпает через ~15 минут; пока OBS открыт, плашка не даёт ему уснуть. Первый запуск OBS за день — плашка появится примерно через минуту. Если сервер перезапустится и «забудет» худ, плашка сама вернёт ему настройки — ссылки в OBS менять не нужно.

**Если HLTV блокирует сервер** (в пульте ошибка про Cloudflare) — включите ручной режим, либо поставьте на свой VPS (ниже), где есть запасной путь через Chromium.

Дописки к адресу плашки: `?scale=1.3` — размер, `?align=right` — прижать вправо, `?nologo=1` — без логотипов, `?debug=1` — показывать ошибки.

## На своём VPS

```bash
git clone https://github.com/Qz1st/hltv-hud && cd hltv-hud
docker compose up -d        # сайт на 80 порту, данные в ./data
```

## Локально на Windows (exe)

`node build.js` собирает `dist/HLTV-Score-Widget.exe` (нужен [bun](https://bun.sh)). Работает без окон: плашка `http://localhost:52713/widget`, пульт `http://localhost:52713/`.

## Переменные окружения

| Переменная | Что делает |
|---|---|
| `CLOUD=1` | серверный режим (худы по ссылкам). На Render включается сам |
| `SECRET` | секрет для ключей пультов; должен не меняться между перезапусками |
| `PORT` | порт (на Render задаётся автоматически) |
| `DATA_DIR` | куда сохранять худы |
| `BROWSER_FALLBACK=0` | не использовать запасной Chromium |
| `MAX_ROOMS` | максимум худов (по умолчанию 40) |
